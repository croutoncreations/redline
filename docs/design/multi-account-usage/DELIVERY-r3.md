## What r3 shows
- **One Claude tile.** Its header (`Claude · 3 accounts · 1 of 3 dispatching`) stays fixed on every page. The pager strip
  has an Overview control, segment dots (wider Overview segment; used-up accounts in dark red), 40 dp ‹ › buttons, and a
  text label ("Overview · swipe left for each account" / "Account 2 of 3").
- **Overview:** each row has "Details ›", which jumps to that account's page.
- **Account pages:** "‹ Overview" returns to Overview. Back also returns to Overview first. › is disabled on the last page.
- **Corrected floor copy:** Personal reads "Dispatching · no weekly floor armed yet · 50% floor arms in 4h", with faint
  (unarmed) floor ticks.
- **States shown:** dispatching (page 1), 5-hour used up and held with no rotation (page 2), monitor only / not routed with
  no queue actions (page 3).
- Unchanged and still valid from r1 (not re-rendered): 05 states, 06 one account, 07 many accounts, 08 chooser, 09 queue.
